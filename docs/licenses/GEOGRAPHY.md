# Cartographic sources

Natural Earth — public domain: https://www.naturalearthdata.com/about/terms-of-use/

Source files from https://github.com/nvkelso/natural-earth-vector:
- geojson/ne_110m_admin_0_countries.geojson
- geojson/ne_50m_admin_1_states_provinces.geojson (Minas Gerais and Goiás only)

Downloaded 2026-11-12. Simplified locally by distance threshold (countries 0.7°, states 0.08°), rounded to 0.001°, stored in public/geo/boundaries.json. These are generalized boundaries for orientation, not street maps or surveyed store locations. Google Maps is a separate interactive embed with its original attribution.
